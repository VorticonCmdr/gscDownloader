# GSC crawl stats downloader

This is the code repository for the Chrome extension [GSC crawl stats downloader](https://chrome.google.com/webstore/detail/gsc-crawl-stats-downloade/bpekjbefojkhefgcfhfeohjfncbpioam/). With the help of this extension you can download all the crawl stats files in Google Search Console with one click (instead of 42).

For more information on this topic please visit https://valentin.app/gscDownloader.html
