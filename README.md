# GSC Crawl Stats Downloader

A Chrome extension for efficiently downloading and visualising Google Search Console crawl statistics. Supports scheduled automatic downloads, interactive charts, and CSV export.

## Features

- **Download crawl stats** across all categories (response codes, file types, purpose, Googlebot type) for any GSC property you have access to
- **Interactive chart** (Billboard.js) with selectable metrics and categories; instant legend toggle; **Invert** button to flip the visible series selection
- **Filterable table** (Tabulator) with per-column header filters, sorting, pagination, and CSV export
- **Scheduled downloads** via Chrome alarms — run daily or weekly at a chosen time of day (and day of week for weekly jobs), even when no extension tab is open. GSC crawl stats update at most once a day, so faster intervals aren't offered
- **Data freshness indicator** — latest data date, coloured when it gets stale; one click to update
- **Stored Properties list** on the Options page — browse all properties with stored data, see date ranges, open them in the chart view, or delete individual datasets
- **Backup & restore** — export all stored data as a ZIP; preview before restoring via an explicit Restore button
- **Failure alerts** — a red badge on the toolbar icon when a scheduled download fails
- **Light & dark** — follows the system colour scheme
- **Account indicator** — shows the currently signed-in Google account and prompts to sign in when not authenticated
- **Property autocomplete** — reads all accessible GSC properties from the page and populates a searchable datalist

## Installation (from source)

### Prerequisites

- Node.js ≥ 20.19 (required by Vite 8)
- npm ≥ 9

### Build

```bash
npm install
npm run build
```

The extension is output to `dist/`.

### Load in Chrome

1. Open `chrome://extensions`
2. Enable **Developer mode** (top right toggle)
3. Click **Load unpacked** and select the `dist/` folder

## Development

```bash
npm run dev      # Rebuild dist/ on file changes (no HMR — reload the extension)
npm run build    # Production build → dist/
npm run lint     # ESLint over src/
npm run package  # Build + zip → extension.zip
```

### Releasing

`package.json` is the single source of truth for the version. `npm run build` syncs it into
`src/manifest.json` (via `scripts/sync-version.js`), so never edit the manifest version by hand.

```bash
npm version minor          # or patch/major — bumps package.json, syncs manifest, commits, tags vX.Y.Z
git push && git push --tags  # tag triggers the Release workflow → extension.zip on GitHub Releases
```

## Usage

### Downloading data

1. Click the extension icon. The crawl stats page opens (or comes to the front if it's already open). On first use, a three-step card walks you through signing in, choosing a property and downloading
2. If you are signed in to GSC, your properties are listed in the property box; ones that already have data in this browser are marked **data stored**
3. Pick a property and click **Download · *property*** → **Download data** to fetch all crawl stat categories. The progress bar shows which section is being downloaded
4. **Download & save ZIP files** does the same and also saves the 43 raw GSC exports to `Downloads/gscData/`
5. The **Latest data** link next to the property shows how old your data is (amber after a week, red after two); click it to update
6. Use the chart controls to switch metric (crawl requests, download size, response time) and breakdown (response code, file type, purpose, Googlebot type, total). **Invert** flips which series are shown
7. Filter the table per column (type list, `≥ min` for numbers, date prefix), then **CSV** → **Filtered rows** or **All rows**. Sizes are shown as KB/MB in the page; the CSV keeps exact byte counts

If you're signed out, a banner with **Retry** appears. Sign in in the other tab and come back; the page reconnects by itself.

The pages follow your system's light/dark setting.

### Settings

Open **Settings** with the gear icon on the crawl stats page (or `chrome://extensions` → Details → Extension options).

#### Scheduled downloads

1. Enter a property exactly as in Search Console (`https://example.com/` with the trailing slash, or `sc-domain:example.com`); your GSC properties are suggested
2. Choose **Daily** or **Weekly**, a local time (e.g. `03:00`), and for weekly jobs the day of the week
3. Click **Add**. Chrome runs the download at that local time (DST-safe) while it's open; if Chrome was closed at that time, the download runs the next time it starts
4. **⚡ Run now** triggers a job immediately
5. If a run fails (e.g. you were signed out of Google), the toolbar icon shows a red **!**, the crawl stats page shows a banner, and the job's row shows **Failed** with the error. The badge clears once the job succeeds or is removed
6. Each export is saved as soon as it arrives, so an interrupted run still keeps what it fetched

Jobs created with hourly / 6-hour / 12-hour intervals in v2.1 or earlier are migrated to daily automatically.

#### Stored data

Every property with data in this browser, with its coverage (days stored, first date) and latest data date:

- **View** (graph icon) opens the crawl stats page for that property, even without an active GSC session
- **Delete** (trash icon) removes its stored data. Click once to arm, again within 4 seconds to confirm

#### Backup & restore

- **Export all data** saves all stored crawl data and schedules as a dated ZIP
- **Restore from a backup…** opens the drop area. Drop a backup ZIP (or choose a file) to see what it contains before anything is written
- **Restore** merges the backup into storage. Dates you have locally but the backup doesn't are kept; for dates in both, the backup's values win. Restored schedules are re-armed immediately

## Privacy

All data stays on your device (`chrome.storage.local`). The extension only talks to `search.google.com` using your existing session; it has no server, analytics or third parties. Full policy: [decompile.tools/gscDownloader/#privacy](https://www.decompile.tools/gscDownloader/#privacy)

## Requirements

- Google account with access to Google Search Console
- The extension must be able to reach `https://search.google.com/` — it uses your browser's existing GSC session (cookies) to authenticate
